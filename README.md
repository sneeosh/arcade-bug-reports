# KennyATX Arcade bug reports

Open a game’s **Report a bug** link in the [arcade](https://games.kennyatx.com/) to start a GitHub issue with the game name already filled in. Include the steps that reproduce the bug, what you expected, what happened, and your browser or operating system.

Issues here are public. This repository contains player feedback for games whose source repositories are private or have their own issue tracker disabled.
